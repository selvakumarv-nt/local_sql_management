        SQLite Compatibility & Notes

        This playground runs an authentic local SQLite 3 WebAssembly engine. SQLite follows standard SQL-92 with additions, but differs from enterprise servers like Oracle or MS SQL:

        • SQLite has dynamic data typing (INTEGER, REAL, TEXT, BLOB, NUMERIC).
        • Stored procedures (PL/SQL) and packages are not part of SQLite standard syntax.
        • Foreign key constraints require PRAGMA activation (handled automatically in this playground).
        • Common functions: LENGTH(), SUBSTR(), ROUND(), DATETIME('now') are native.
